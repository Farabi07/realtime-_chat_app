# Real-Time Chat API 

This project is a backend-only real-time chat system built with Django,Django Channels, and JWT authentication.
## Tech Stack

- Python 3
- Django 4
- Django REST Framework (DRF)
- Django Channels
- Redis
- JWT (using `djangorestframework-simplejwt`)

git clone https://github.com/Farabi07/realtime-_chat_app.git

## Register API


POST /user/signup/
## Login API

POST POST /user/login/

ws://127.0.0.1:8000/ws/chat/global/?token= " jwt user token"
